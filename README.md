# 🎁 Jogo do Amigo Secreto

O **Amigo Secreto** é um jogo divertido onde você pode sortear aleatoriamente um amigo secreto para cada participante!  

## 📜 Como Jogar

1. **Adicionar Amigos**  
   - Digite o nome de um participante no campo de texto.  
   - Clique no botão **"Adicionar"** para inserir o nome na lista.  

2. **Sortear o Amigo Secreto**  
   - Após adicionar todos os participantes, clique no botão **"Classificar Amigo"** para realizar o sorteio.  

3. **Descubra seu Amigo Secreto**  
   - O sistema irá gerar pares secretos automaticamente e exibir o resultado.  

## 🛠 Funcionalidades

✅ Adicionar participantes facilmente.  
✅ Sortear amigos de forma aleatória.  
✅ Garantia de que ninguém se sorteia a si mesmo.  

> *Prepare-se para um jogo cheio de surpresas e diversão!* 🎉
